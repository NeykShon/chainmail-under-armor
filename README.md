# Chainmail Under Armor

**Chainmail Under Armor** — мод для **Minecraft Fabric 26.1.1**, добавляющий возможность носить кольчужную броню **под основной бронёй**.

Кольчуга становится дополнительным защитным слоем: сначала игрок надевает кольчугу в слот брони, а затем поверх неё — обычный элемент брони. Это позволяет комбинировать кольчужную и другую броню, создавая дополнительную защиту.

> **Статус проекта:** В разработке (Альфа)
>
> **Последняя стабильная версия:** alpha-0.7

---

## Основная механика

Мод добавляет дополнительный слой экипировки для каждого элемента брони.

Сначала в слот брони помещается кольчуга, после этого поверх кольчуги можно надеть элемент обычной брони.

Кольчуга не может быть надета поверх другой кольчуги. Это предотвращает бессмысленное дублирование одинаковых элементов экипировки.

Чтобы снять кольчугу, необходимо сначала снять основную броню, находящуюся поверх неё.

## Дополнительная защита

! пока не работает как надо

Кольчужная броня, находящаяся под основной бронёй, уменьшает количество урона, которое проходит через верхний слой брони.

Чем больше элементов кольчуги надето, тем сильнее дополнительная защита.

| Элемент кольчуги   | Дополнительное снижение урона |
| ------------------ |------------------------------:|
| Койф               |                       **+4%** |
| Кольчуга           |                       **+8%** |
| Кольчужные поножи  |                       **+5%** |
| Кольчужные ботинки |                       **+2%** |

Проценты складываются между собой в зависимости от количества надетых элементов.

Полный комплект кольчуги даёт:

**4% + 8% + 5% + 2% = 19% снижения урона, прошедшего через верхний слой брони.**

## Установка

1. Установите **Minecraft Fabric 26.1.1**.
2. Установите необходимую версию **Fabric API**.
3. Скачайте `.jar` файл мода из раздела Releases.
4. Переместите файл в папку:

```text
.minecraft/mods
```

5. Запустите Minecraft через профиль Fabric.

## Known issues

Проект находится на стадии **Alpha**, поэтому возможны ошибки и нестабильное поведение.

На текущем этапе разработки возможны проблемы, связанные с:

* сохранением состояния дополнительной экипировки;
* сменой игрового режима;
* перезаходом в мир;
* обработкой смерти и восстановления игрока;
* взаимодействием с некоторыми механиками Minecraft;

Некоторые из этих проблем уже известны и будут исправляться в следующих версиях.

Если вы обнаружили ошибку, пожалуйста, создайте **Issue** на GitHub и приложите:

1. Версию Minecraft.
2. Версию Fabric Loader и Fabric API.
3. Версию мода.
4. Список установленных модов.
5. Подробное описание проблемы.
6. Шаги для воспроизведения ошибки.
7. Лог игры, если он связан с проблемой.
