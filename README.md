# Я делаю мод под названием "Chainmail under Armor" для Minecraft-Fabric 26.1.1, который позволит надевать кольчугу под основную броню, чтоб увеличить свою защиту.

Механика проста: вы помещаете кольчугу в слот для брони и поверх неё надеваете любой другой доспех (кроме кольчуги, чтоб не получилось масло масляное). Чтобы снять кольчугу вам нужно сначала снять броню.

Ради баланса суммарная защита от кольчуги и брони вместе будет меньше, чем защита по отдельности. Вот таблица защиты кольчужной брони когда она находится под основным доспехом:
```
Элемент экипировки | Защита без брони сверху | Защита с бронёй сверху
Койф               | +2                      | +1
Кольчуга           | +5                      | +3
Кольчужные поножи  | +4                      | +2
Кольчужные ботинки | +1                      | +1
```

Зачарования кольчуги будут недоступны, хотя я ещё могу ввести механику объединения чар кольчуги и брони.

Запланированная дата выхода мода - через несколько дней. Мод будет опубликован на Modrinth и других площадках.
